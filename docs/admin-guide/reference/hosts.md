# Hostnames

[← Admin Guide](../README.md) · [Home](../../README.md)

Use the public login hostname documented in the [SSH login guide](../../user-guide/02-ssh-login.md). Other internal hostnames, addresses, DNS overrides, interface data, and endpoint mappings are maintained in the restricted operator inventory.

Do not copy private address tables, host-key fingerprints, or credential-bearing connection settings into this public repository.
