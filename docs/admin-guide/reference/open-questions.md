# Operational evidence gaps

Open infrastructure questions and host-specific findings are tracked in the restricted coordination and operations sources. This public page intentionally does not reproduce endpoint inventories, firewall exposure analysis, certificate metadata, storage paths, or unresolved security findings.

When an issue is approved for public tracking, describe the user impact and required decision without exposing restricted implementation details. Assign an owner only when responsibility is evidenced and accepted.
