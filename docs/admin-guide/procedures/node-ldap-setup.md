# Node identity onboarding

Configure Linux identity integration only through the approved deployment workflow. Validate directory reachability, certificate verification, account and group resolution, access policy, and an authorized login using a non-privileged test identity. Confirm cache behavior and recovery before enabling user access.

Directory endpoints, search bases, bind credentials, TLS files, host-specific filters, SSH policy, and privileged commands belong in restricted operator documentation. Do not paste secret-bearing identity configuration into Git or chat.
