# Shared-storage operations

Filesystem health, metadata services, chunk placement, replication, quota, trash recovery, storage expansion, and failover are administrator-only operations. Use the current protected storage inventory and approved recovery procedure.

Before repair, record current service and mount state, confirm the replica/recovery plan, and preserve a protected configuration snapshot. Verify data availability and consistency after recovery. Never use an old node address, mount recipe, or replication command without confirming it matches the active deployment.
