# Node deployment

Node enrollment is an administrator-only operation. Use the version-controlled deployment workflow for the target service and its approved protected inventory. Verify identity resolution, authorization, scheduler or service membership, storage, monitoring, firewall scope, SSH host identity, and recovery before handing a node to users.

Host-specific commands, network values, trust material, and privileged access details are maintained in restricted operational sources, not this public guide. A successful package install alone does not establish acceptance.
