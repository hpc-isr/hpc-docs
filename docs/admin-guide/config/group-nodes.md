# Group nodes

Research groups may have separately administered compute systems. Their host mappings, addresses, storage, firewall policy, identity restrictions, and recovery details are maintained by the responsible administrators in an access-controlled source.

The public user guide explains how to request access and use a group system. This page does not publish a host inventory or imply that one group's node is configured like another's.
