# Shared storage

Storage may include shared filesystems, durable block volumes, and node-local temporary storage. Their availability, replication, permissions, and recovery properties differ. Users should store durable results only in the paths explicitly documented for their service.

Filesystem topology, host exports, devices, mount configuration, addresses, ports, service commands, and recovery steps are restricted operational data. Verify them from the protected inventory and current host read-back before maintenance.
