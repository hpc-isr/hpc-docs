# Container services

Container runtime versions, host mounts, networks, socket access, published ports, Compose files, secrets, image sources, and service placement are administrator-only details. Use the approved deployment automation and restricted inventory for the target host.

Treat access to a privileged container runtime or its control socket as host-administrator access. Do not copy environment files, credentials, internal mount paths, or service endpoints into public examples.
