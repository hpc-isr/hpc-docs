# Web entry services

Web services may use a reverse proxy and centrally managed TLS certificates. Host routing, backend names, container configuration, exposed ports, certificate files, DNS records, and administrative dashboards are restricted.

For user access, follow the public application guide. For renewal or outage response, use the approved restricted deployment and certificate-management procedures. Never disable certificate verification to work around a trust failure.
