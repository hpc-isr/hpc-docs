# Linux identity integration

Linux systems use centrally managed directory identities through the configured name-service and authentication stack. Scheduler users must resolve consistently on the login/controller and compute systems.

Exact SSSD files, directory endpoints, search bases, bind identities, access filters, certificate trust configuration, cache policy, and recovery commands are restricted operational data. Use the authoritative automation and verify the live target before changing it. Do not copy secret-bearing configuration into this public repository.
