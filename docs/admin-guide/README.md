# Administrator documentation

[← Home](../README.md)

This public repository contains user-safe overview material only. Detailed host inventories, storage and network topology, firewall policy, authentication configuration, certificates, deployment procedures, monitoring and recovery commands belong in appropriately access-controlled operator sources.

Use the private administrator documentation for the dated as-built and use `hpc-automation` for deployable implementation and procedures. Verify current repository access controls before adding operational detail. Do not put secrets, private keys, access tokens, populated user manifests, or host fingerprints in Git.
