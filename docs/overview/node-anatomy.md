# Compute environment

[← Overview](README.md) · [Home](../README.md)

SLURM allocates compute resources to jobs. Storage available inside a job can include shared project or home storage and node-local temporary space; availability and persistence depend on the configured filesystem. Store durable results only in approved persistent locations and keep a separate backup when required.

Exact disk devices, filesystem mounts, storage topology, service placement, and recovery steps are restricted operational details. Consult the administrators before relying on a path for durability or capacity.
